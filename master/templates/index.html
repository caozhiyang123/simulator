🗑️ Batch Delete File

Search and delete files matching a wildcard pattern across multiple directories recursively.

📖 Usage Guide

Purpose: Search and delete files matching a wildcard/glob pattern across multiple directories recursively.

Steps:

  1. Enter a filename pattern with wildcards (e.g. CalacaBingo*.txt, *.log, test_??.dat).
  2. Enter target directories to search in (supports multiple).
  3. Optionally enter directories to exclude from search.
  4. Click Check All Files to preview all matching files found (with select all/none/inverse).
  5. Select the files you want to delete, then click Batch Delete (a confirmation dialog will appear).

Wildcard support: * matches any characters, ? matches a single character.

🗑️ Batch Delete File (multi-node)

Search and delete files matching wildcard patterns across multiple nodes at once. Assumes selected nodes share an identical directory structure.

📖 Usage Guide

Purpose: Search and delete files matching wildcard patterns across multiple nodes in one action.

Steps:

  1. Select the nodes to operate on (Master is checked by default). Target Directories are auto-filled with each selected node's production_dir root.
  2. Enter one or more filename patterns (click + to add more, e.g. CalacaBingo*.txt, *.log).
  3. Adjust or add to Target Directories as needed. Supports */? wildcard patterns — patterns are resolved per node independently.
  4. Optionally enter directories to exclude.
  5. Click Check All Files to preview matching files per node.
  6. Click Batch Delete to delete all found files on every selected node (a confirmation dialog will appear).

Note: Deletion is irreversible. Each node's Target Directories and filename patterns are resolved independently.

📦 Batch Override File

Replace a file across multiple subdirectories by matching the filename recursively.

📖 Usage Guide

Purpose: Replace/override files across multiple subdirectories by matching filename recursively.

Steps:

  1. Enter one or more source file full paths (click + to add more). These files will be used as the replacement content.
  2. Enter target directories to search in (supports multiple).
  3. Optionally enter directories to exclude from search.
  4. Click Check All Files to preview all matching files found (with select all/none/inverse).
  5. Click Batch Override to replace all matching files with the source files.
  6. Click Batch Delete to delete selected files (requires confirmation).

Note: Override matches files by filename. Source file must exist locally. The source file itself is skipped during override.

📦 Batch Override File (multi-node)

Replace the same file across multiple nodes at once. Assumes selected nodes share an identical directory structure.

📖 Usage Guide

Purpose: Replace the same file across multiple nodes in one action, instead of repeating the single-node Batch Override workflow once per node.

Steps:

  1. Select the nodes to operate on (Master is checked by default). Target Directories are auto-filled with each selected node's production_dir root as soon as you check/uncheck a node.
  2. Enter one or more source file full paths (click + to add more). These files will be used as the replacement content.
  3. Adjust or add to Target Directories as needed. Supports */? wildcard patterns (e.g. E:/.../SimC*/math/Game/configuration) — patterns are resolved per node, so a directory pattern belonging to a different node simply matches nothing on this node instead of causing a "Directory not found" error.
  4. Optionally enter directories to exclude.
  5. Click Check All Files to preview matching files per node.
  6. Click Batch Override to replace all matching files with the source files on every selected node.

Note: Override matches files by filename. Each node's Target Directories are resolved independently, so it's safe to mix Windows and Linux-style paths when nodes run different OSes.

✏️ Batch Edit File

Batch append/replace key=value entries in .properties files across multiple directories. View Files supports all file types.

📖 Usage Guide

Purpose: Batch append or replace key=value entries in .properties files across multiple directories.

Steps:

  1. Enter the properties file name to search (e.g. stresstest.properties).
  2. Enter key=value content entries (click + to add more, e.g. WildEastGameIds=200).
  3. Enter target directories to search in.
  4. Optionally enter directories to exclude.
  5. Click Check All Files to preview matching files.
  6. Click Batch Edit to apply changes: existing keys get updated, missing keys get appended at end of file.
  7. Click View Files to browse file contents with preview cards. Click Expand to edit and save individual files.

Note: Batch Edit currently only supports .properties files. View Files supports all file types.

⬆️ Batch Upload File

Upload source files to matching directories found via glob pattern search.

📖 Usage Guide

Purpose: Upload (copy) source files to multiple target directories found via glob pattern matching.

Steps:

  1. Enter one or more source file full paths (click + to add more).
  2. Enter target directory patterns (supports * wildcard for glob matching, e.g. E:/path/*/simulator/lib).
  3. Optionally enter directories to exclude.
  4. Click Check All Files to preview all matching directories (with select all/none/inverse).
  5. Click Batch Upload to copy source files into all selected target directories.

Example: Source: D:\tools2\b2b\B2BBMM\B2BSimulator\simulator\B2BGameSimulator\lib\VBWildBallLogic.jar, Target: E:/temp/ShowBingoSim/*/simulator/B2BGameSimulator/lib will copy VBWildBallLogic.jar to all matching lib directories.

⬆️ Batch Upload File (multi-node)

Upload the same source file(s) to multiple nodes at once. Assumes selected nodes share an identical directory structure under their production/simulator directory.

⬆️ Uploading to selected nodes...

📖 Usage Guide

Purpose: Upload the same source file(s) to multiple nodes in one action, instead of repeating the single-node Batch Upload workflow once per node.

Steps:

  1. Select the nodes to upload to (Master is checked by default). Target Directories are auto-filled with each selected node's production_dir root as soon as you check/uncheck a node.
  2. Enter one or more source file full paths (click + to add more). Source files are always read from Master's local disk.
  3. Adjust or add to Target Directories as needed. Supports */? wildcard patterns (e.g. E:/path/*/simulator/lib) — patterns are resolved per node, so a directory pattern belonging to a different node simply matches nothing on this node instead of causing an error.
  4. Optionally enter directories to exclude.
  5. Click Check All Files to preview matching directories per node.
  6. Click Batch Upload to copy the source file(s) into the matching directories on every selected node.

Note: Each node's Target Directories are resolved independently, so it's safe to leave a mixed list of Windows and Linux-style paths when nodes run different OSes.

⬇️ Batch Download File

Search files by name (supports wildcard *) across directories, then batch download as zip or view contents.

⬇️ Preparing download...
0%
📖 Usage Guide

Purpose: Search files by name (supports wildcard) across directories, then batch download as zip or view contents.

Steps:

  1. Enter a file name to search (supports * wildcard, e.g. CalacaBingo*.txt).
  2. Enter target directories to search in.
  3. Optionally enter directories to exclude.
  4. Click Check All Files to preview matching files (with select all/none/inverse).
  5. Click Batch Download to download selected files as a zip (preserving relative directory structure).
  6. Click Batch View to browse file contents with preview cards. Click Expand to view full content.

Download structure: A temp folder is created in the first target directory, files are copied preserving their relative paths, then compressed as temp.zip for download.

⬇️ Batch Download File (multi-node)

Search and download matching files from multiple nodes in a single combined zip (one subfolder per node), instead of downloading one zip per node manually.

⬇️ Preparing combined download...
0%
📖 Usage Guide

Purpose: Search and download matching files from multiple nodes in a single combined zip, instead of downloading one zip per node manually.

Steps:

  1. Select the nodes to search on (Master is checked by default). Target Directories are auto-filled with each selected node's production_dir root as soon as you check/uncheck a node.
  2. Enter a file name to search (supports * wildcard, e.g. BingoSeven_91_high_vi*.txt).
  3. Adjust or add to Target Directories as needed. Supports */? wildcard patterns — patterns are resolved per node, so a directory pattern belonging to a different node simply matches nothing on this node.
  4. Optionally enter directories to exclude.
  5. Click Check All Files to preview matching files per node.
  6. Click Batch Download (combined zip) to download one zip containing every matched file, organized into one subfolder per node (e.g. master/, 10.147.18.121_5002/).

Note: If a download partially fails on some node, an errors.txt is included inside the combined zip listing which node/file failed, while the rest of the zip still downloads successfully.
